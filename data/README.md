# Data directory

This public repository does not include a knowledge base, school data, uploaded documents, FAISS indexes, or generated vector-store files.

For local development, place your own private knowledge-base files here or upload them through the API. Keep those files out of Git.

Ignored local data includes:

- `data/*.txt`
- `data/*.pdf`
- `data/*.docx`
- `data/*.csv`
- `data/*.xlsx`
- `data/*.jsonl`
- `data/vector_store/`
- `*.faiss`
- `*.pkl`

本公开仓库不包含知识库正文、学校资料、上传文档、FAISS 索引或生成的向量库文件。

本地运行时，请使用者自行准备知识库文件或通过 API 上传，并确保这些文件不提交到 Git。
